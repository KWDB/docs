# 概述

KaiwuDB 分析平台（英文名称 KaiwuDB Insight Platform，简称 KIP）是依托 KaiwuDB 时序数据库打造的一站式时序智能分析平台，面向工业物联网、车联网、新能源、电力、装备制造等典型时序业务场景，提供覆盖数据接入、元数据治理、数据语义建模、可视化分析、AI 智能洞察、任务自动化、报告分发的全链路能力。业务管理人员、运维工程师、数据分析师无需深度掌握 SQL 与数据库底层技术，通过可视化配置与自然语言对话交互，即可快速完成时序数据探查、指标解读、异常识别与趋势预判，高效挖掘时序数据价值，支撑业务数字化、数据驱动决策。

## 功能特性

围绕**数据接入 → 数据语义化 → 可视化分析 → AI 智能解读与告警 → 自动化任务与报告输出**，形成完整时序数据分析闭环，KIP 核心能力如下：
- 自然语言交互：支持以自然语言对话方式发起数据查询、指标统计、图表生成、数据解读；内置知识库，可独立解答 KaiwuDB 产品特性、语法、生态相关问题；支持上传附件辅助问答，降低数据分析使用门槛。
- 数据源管理：统一管理多套 KaiwuDB/KWDB 数据库连接，支持连接启用 / 禁用、连接测试、SSL 证书、SSH 隧道、访问超时等配置；支持多数据源隔离，适配多集群、多租户时序数据接入场景。
- 数据语义化：为库、表、列、标签等数据库对象赋予业务含义、指标口径、业务描述；支持系统自动语义生成与人工校准维护；以树状结构展示数据源、库表、字段元数据，让原始结构化数据转化为大模型可理解、可推理的业务知识，是所有 AI 分析能力的基础。
- 可视化分析与管理：
  - 丰富图表组件：支持表格、折线图、柱状图、面积图、饼图、漏斗图、玫瑰图、散点图、雷达图、仪表盘等，适配时序趋势、分类对比、占比统计、多维评估等时序分析场景；支持图表 / 表格切换、类型一键转换、放大查看、多格式导出。
  - 仪表板全生命周期管理：支持仪表板新建、布局拖拽调整、重命名、删除；图表来源包括对话生成、仪表板内对话建图、智能推荐、外部 Grafana 面板嵌入；支持单图表手动刷新、仪表板定时自动刷新。
  - 图表智能解读：AI 自动解析图表指标、时间范围、数据分布，识别趋势（上升 / 下降 / 平稳 / 周期性波动）、突变点与异常点，输出业务解读结论并给出优化建议。
- 图表推荐：基于数据源元数据与已构建的业务语义，自动识别表结构、指标类型、时序特征，主动推荐适配的分析图表；支持批量采用或弃用，采纳后的图表自动归入图表库，可快速添加至仪表板，大幅降低数据分析对 SQL、可视化技能的依赖。
- 高级分析：
  - 数据填补：针对时序断点、缺失采样点，支持线性插值、样条插值、前向填充、后向填充、季节均值等多种填补策略，修复时序序列，提升数据集连续性，保障后续预测、检测效果。
  - 趋势预测：基于历史时序样本，学习指标变化规律、周期特征，在规律延续假设下外推生成未来预测序列，支持自定义预测步数、时间粒度、置信区间、季节周期配置。
  - 异常检测：内置 Z‑Score、IQR、MAD、季节分解等多种时序检测算法；支持自定义阈值、周期参数；检测到异常后生成告警记录，可通过 Webhook、MQTT 推送告警消息至第三方平台。
  - 根因分析：针对已识别的异常事件，结合元数据、业务语义、历史时序基线，自动生成异常诱因假设并验证，输出结构化根因报告与可落地处置建议。
- 自动化任务编排：支持三类定时智能任务：Agent 任务、仪表板定期解读任务、时序异常告警规则；任务支持手动立即执行、周期调度、执行记录留存，可对接通知渠道实现结果自动推送。
- 提示词、MCP 工具与自定义技能：支持自定义提示词模板、MCP Server 接入、业务技能包上传，可扩展 Agent 能力，适配行业专属分析流程、私有工具调用。
- 报告输出与分发：一键将仪表板内全部图表、AI 解读结论、异常事件汇总生成 Word 分析报告；支持在线预览、本地下载，也可配置定时任务，通过 Webhook 自动推送报告至第三方系统或通知通道。
- 权限与多用户隔离：基于 KaiwuDB 账号体系统一认证，多用户数据隔离；不同用户仅可见自身创建的对话、数据源、仪表板、任务，保障数据隐私安全。

## 核心概念

| 概念 | 说明 |
| ---- | ---- |
| 数据源 | KIP 接入的 KaiwuDB/KWDB 数据库连接配置，包含地址、端口、账号密码、SSL 证书、SSH 隧道、超时、许可证等参数；支持启用、禁用、连通性测试，实现多集群时序数据接入。|
| 元数据 | 数据源下，当前用户权限可见的数据库对象集合，包含数据库、数据表、列、标签等对象及其 Schema 结构、字段类型、索引信息，是语义建模的基础原始信息。|
| 数据语义 | 由系统自动生成或人工校准，附加在库、表、列、标签上的业务描述、指标口径、单位、业务场景等信息；将原始字段映射为业务概念，是大模型理解数据、生成 SQL、解读图表的核心前提。|
| 图表库 | 全局图表资源池，汇总对话生成、仪表板创建、智能推荐采纳、外部导入的全部图表；支持图表检索、删除、复用，可添加至任意仪表板，实现图表资产复用。|
| 仪表板 | 可视化看板载体，由一张或多张图表组成；支持拖拽布局、定时刷新、AI 整板解读、洞察汇总；用于常态化指标监控、周期性数据分析汇报。|
| Agent	| KIP 智能分析代理，基于 LangGraph + DeepAgents 编排框架构建；接收用户自然语言请求，调度模型、MCP 工具、SQL 执行、时序分析算子，串联查询、绘图、预测、异常检测、报告生成等子任务。|
| 提示词 | 预设的指令模板，用于约束 LLM 输出规范、分析范式；支持 system /user/assistant 角色、版本管理、导入导出，供 Agent 任务、对话分析调用。|
| MCP Server|  遵循 MCP 协议的外部工具服务，可为 Agent 提供扩展能力，支持接入自定义工具，实现数据库之外的能力调用。|
| 智能任务| 后台定时调度任务，分为 Agent 任务、仪表板解读任务、异常告警规则三类；支持周期调度、手动触发、执行日志留存、结果通知推送。|
| 洞察 | AI 基于仪表板指标、时序基线、语义信息自动提炼的结论集合，包含趋势总结、异常点、风险提示；整板解读后集中展示，支持查看明细、刷新洞察、生成正式报告。|
