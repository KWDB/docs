# KWDB 3.3.0 发版说明

KWDB 是一款面向 AIoT 场景的分布式、多模融合的数据库产品，支持在同一实例同时创建时序库和关系库，并融合处理多模数据，具备千万级设备接入、百万级数据秒级写入、亿级数据秒级读取等时序数据高效处理能力，具有稳定安全、高可用、易运维等特点。面向工业物联网、数字能源、车联网、智慧产业等领域，提供一站式数据存储、管理与分析的基座。
KWDB 3.3.0版本在保持原有特性的基础上，在时序数据处理、生态工具、安装部署等方面引入了多项新特性与优化。

## 新增特性

###  数据库对象管理

- 时序支持视图管理：
  - 支持视图的创建、修改、删除和查看；
  - 关系和时序下均支持引用权限范围下的表数据，支持跨膜查询；

### 数据管理与查询

- 数据发布：
  - 支持灵活配置订阅对象，包含时序库、时序表、带 WHERE 条件的查询语句；
  - 发布数据支持时序数据删除和更新操作；
  - 发布数据对象包含乱序插入的数据、IMPORT 语句导入的数据、任务开启前或暂停期间更新的数据

- 数据推送：支持将数据库中的数据实时推送至 Kafka 主题；
  - 历史数据推送控制：支持通过参数配置是否推送历史数据
  - 灵活推送范围：支持单时序库、单时序表或多个时序表的数据推送
  - 全面过滤支持：支持所有 metrics 和 tag 列的过滤功能
  - 即时推送配置：支持为每个推送任务独立配置是否立即推送
  - DDL 操作推送：完整支持 DDL 操作推送，包括： 
    - create table（创建表）
    - drop table（删除表）
    - alter table（修改表结构）

###  运维管理

- range报告下载：提供 Kwbase debug range-repor 子命令，拉取指定 rangeID 的诊断信息，并在本地生成一份静态 html 报告；

## 重要变更

###  生态 & 工具

- KaiwuDB 开发者中心：时序支持视图管理。

- KaiwuDB JDBC：JDBC 驱动支持 prepare extend 写入模式，新增私有 ‘j/k/l’ 消息，按表对象直插数据，实现数据的高速写入。

- 安装部署支持高级自定义安装：
  - 支持为每个节点设置不同的数据服务端口、adminUI端口、数据目录；
  - 支持在一台服务器上安装多个节点；

### 操作系统和环境

- •提供 windows11 环境的二进制文件，支持关系操作；

##  升级说明

- **多副本集群**：支持 KWDB 3.0.x、3.1.x 和 3.2.x 版本离线升级至 3.3.0

- **单副本集群**：支持 KWDB 3.0.x、3.1.x 和 3.2.x 版本离线升级至 3.3.0

- **单机版本**：支持 KWDB 3.0.x、3.1.x 和 3.2.x 版本离线升级至 3.3.0

- **KWDB 1.x、2.x 版本**：支持通过导入导出方式升级至 3.3.0
